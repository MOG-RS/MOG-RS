# MOG-RS Website

A modern React-based website for the **MOG-RS Project** — showcasing research, projects, and network collaborations.

## 🚀 Features
- Responsive design for desktop and mobile
- Multi-language support
- Organized project and research sections
- Contact form integration
- Partner and team showcase

## 🛠️ Tech Stack
- **Frontend:** React, JavaScript, CSS
- **Build Tool:** Create React App
- **Version Control:** Git & GitHub

## 📂 Project Structure
MOG-RS/
├── public/ # Static files (HTML, images, icons, PDFs)
├── src/ # React components and styles
│ ├── components/ # Reusable UI components
│ ├── asset/ # Images and graphics
│ └── translations.js # Language translations
├── package.json # Dependencies and scripts
└── README.md # Project documentation

   ```bash
   git clone git@github.com:MOG-RS/MOG-RS.git

Install dependencies

Build for production
